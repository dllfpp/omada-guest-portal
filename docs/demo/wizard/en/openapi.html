Open API application

The portal reads device details and creates its operator through the controller’s Open API. Create an application for it:

Omada controller 6.2.0 found.

  1. In the controller switch to the Global view and open Settings › Platform Integration › Open API.
  2. Click Add New App. Give it a name (for example “Guest portal”), choose mode Client, role Administrator, and in Site Privileges the site with the guest Wi-Fi.
  3. Save, click the eye icon next to the new app and copy the Client ID and the Client Secret.

With the Administrator role the wizard can create the hotspot operator for you. With a Viewer role, create the operator yourself (Hotspot › Operators) and choose “existing operator” later.
