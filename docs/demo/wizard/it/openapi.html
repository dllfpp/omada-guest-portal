Applicazione Open API

Il portale legge i dati dei dispositivi e crea il suo operatore tramite l’Open API del controller. Crea un’applicazione apposta:

Trovato il controller Omada 6.2.0.

  1. Nel controller passa alla vista Global e apri Settings › Platform Integration › Open API.
  2. Premi Add New App. Dai un nome (per esempio “Portale ospiti”), scegli la modalità Client, il ruolo Administrator e in Site Privileges il sito con la Wi-Fi ospiti.
  3. Salva, premi l’icona dell’occhio accanto alla nuova app e copia Client ID e Client Secret.

Con il ruolo Administrator il wizard può creare per te l’operatore hotspot. Con il ruolo Viewer crea tu l’operatore (Hotspot › Operators) e più avanti scegli “operatore esistente”.
