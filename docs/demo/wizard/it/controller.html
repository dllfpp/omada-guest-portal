Controller Omada

L’indirizzo del controller Omada che gestisce gli access point della Wi-Fi ospiti, come lo apri nel browser.

Per esempio https://192.168.0.10:8043 per un software controller, oppure https://192.168.0.2 per un OC200/OC300. Il certificato autofirmato va bene.
